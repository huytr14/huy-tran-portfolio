# huy — Gia Huy Tran's Portfolio

Live: https://huy-tran-portfolio.vercel.app

Personal portfolio of **Gia Huy Tran** — Full-Stack Developer & Technical Marketer based in Ho Chi Minh City, Vietnam.

Dark Navy single-page design: numbered sections (01 About / 02 Experience / 03 Projects / 04 Contact), company tabs for experience, fixed social and email rails. Content follows his two CVs (Developer + Technical Marketing).

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS 3
- Deployed on Vercel

## Run locally

```bash
npm install
npm run dev
```
